# Liquid Glass Studio

기존 감시실 스타일을 대체하는 사용자 지정 디자인. 핵심은 밝고 친절한 제작 도구와 허구적 콘텐츠 생산 사이의 시각적 모순이다.

- 배경: warm ivory #F1ECE8, mist blue #DCE7ED, soft gray #E5E3E4. 고정된 저대비 오로라 빛을 사용한다.
- 유리: 위쪽·왼쪽 백색 하이라이트, 아래쪽 두께감, 굴절을 연상시키는 옅은 색, 방향 있는 확산 그림자. CSS backdrop-filter 미지원 시 불투명한 밝은 표면으로 대체한다.
- 액션: #7957F5 violet과 lavender #A98BFF, mint #77E1D6, cyan #9BE8F2. REPRODUCE는 볼록한 젤리 표면이다.
- 경고·허구: signal red #F05261의 옅은 표면과 충분히 어두운 텍스트. 색뿐 아니라 항상 라벨을 함께 표시한다.
- 텍스트: primary #202026, secondary #686873. 로컬 Geist variable + 한국어 시스템 산세리프. 모노스페이스는 세대·시간·기술 메타데이터에만 사용한다.
- 패널 radius 28~32px, 카드 22px, 입력 18px, 버튼 pill. 기사는 가독성을 위해 거의 불투명한 종이색을 쓴다.
- 레이아웃: 데스크톱 관찰 / 큰 이미지 / 기사 3열, 태블릿 2열+하단 기사, 모바일 3개 탭+고정 생성 버튼. 하단 이미지 타임라인에서 세대를 선택한다.
- 생성된 이미지가 나타날 때만 카드를 띄우고 이전 카드가 뒤에 남는다. 실제 생성 중에만 빛이 흐른다. reduced-motion에서는 모든 이동을 제거한다.

기존 API, 세션 데이터, 생성 모델은 변경하지 않는다. 사용자가 제공한 Liquid Glass Kit 이미지의 두꺼운 하이라이트, 오른쪽 아래 그림자, 민트·보라 굴절을 물성 기준으로 사용한다.

## Current Quick Surface
사용자의 후속 단순화 요청에 따라 기본 UI는 사진·대화 입력과 기사 결과의 2열로 변경했다. 모바일은 한 열로 이어진다. 기존 유리 재질만 유지하며 REPRODUCE·세대·타임라인·이미지 생성·편집기·모바일 탭은 기본 화면에서 제외한다. 사용자는 입력 후 기사 만들기 한 번으로 로컬 기사를 받는다.
