# 카드뉴스 3장 구성 (2026-11-06)

새 카드뉴스는 커버 1장과 본문 2장이다. 커버는 원본 전체를 유지하고, 본문은 Claude가 기사에서 언급한 실제 디테일의 크롭 좌표를 선택해 최대 2배로 확대한다. 사진에 가림 처리를 하지 않고 크롭하며 표정·행동·사물을 생성하거나 변형하지 않는다. 적합한 크롭이 없으면 원본 전체를 쓴다. 이전 4장 게시물은 계속 조회·게시할 수 있다. 아래 과거 4장 설명보다 이 규약을 우선한다.

# Product

## Platform
web

## Users
관객이 사진과 동의받은 부분 녹취를 제공하고 AI가 콘텐츠를 반복 생산하는 과정을 체험하는 인터랙티브 미디어아트.

## Product Purpose
이미지와 기사가 서로를 재해석하면서 원본의 의미가 이동하는 과정을 보여준다. 인간의 개입도 다음 생성의 자료가 된다.

## Capabilities and Constraints
React·TypeScript·Vite·Tailwind와 기존 Node 백엔드를 사용한다. Ollama gemma3:4b, ComfyUI SDXL, 선택적인 로컬 Whisper만 호출한다. 모든 자료와 결과는 로컬에 보관한다. 원본은 G00에 보존하고 재귀 세대는 직전 생성 결과만 입력받는다. 촬영·녹음·Manual·Auto·Human-in-the-loop·개별 중지·보관함·데모·출처 추정을 유지한다. 사용자 동의와 허구 표시를 약화하지 않는다.

## Brand Commitments
THE OVERHEARD. A Machine That Makes Stories. 사용자가 지정한 Cute Surveillance × Friendly Propaganda Machine × Liquid Glass 방향으로 UI만 교체한다. 사용자가 후속 메시지로 Liquid Glass Kit 참조 이미지를 제공했다.

## Product Principles
- 결과 이미지와 기사를 먼저 보여준다.
- 생성 상태는 실제 작업 상태만 표시한다.
- AI의 출처·의미 비교는 추정이며 사실 검증이 아니다.
- 정보의 축적을 보여주되 조작과 읽기를 방해하지 않는다.

## Accessibility & Inclusion
모바일에서도 관찰·재생산·기사에 접근할 수 있어야 한다. 키보드 조작, 명확한 초점, 충분한 대비와 prefers-reduced-motion을 지원한다.

## Current Surface
사용자 요청으로 기본 화면을 사진·대화 수집과 기사 한 편 생성으로 단순화했다. 재귀·이미지 생성·타임라인·편집기는 기본 화면에서 제외한다. 기존 확장 코드와 저장 세션은 보존한다. 기본 화면은 `/api/generate`를 사용하며 ComfyUI 없이 동작한다.

## Current Audio Input
기본 화면은 직접 대화 입력을 제공하지 않는다. 동의 후 최대 1분 연속 녹음하고 종료 시 로컬 Whisper로 전사한다. 인식된 텍스트만 읽기 전용으로 표시하며 개별 구간·전체 삭제를 제공한다. 누락·무음·전사 실패는 대화 텍스트로 만들지 않는다. ASR 출력을 별도 AI로 교정하거나 창작하지 않는다.

## Observation Publishing POC
로컬 기본 화면은 별도 홈서버가 전달한 관측을 수신하고 AI 초안을 생성하여 사람이 검토·수정·게시한다. 수집 장비 연결은 별도 서버의 책임이다. 수신 데이터는 JSON으로 센서값과 선택적 base64 사진·WAV를 받는다. 저장된 게시문과 공개 JPEG URL로 Instagram Login API를 호출한다. 사람의 클릭만 향후 API 호출로 대체할 수 있게 게시 기능을 서버에 둔다. 기존 `/capture`와 공개 사이트는 유지한다.

## Instagram Unified Login
Meta의 신규 앱 흐름에 맞춰 config_id 기반 로그인·브라우저 확인·토큰 교환·승인 계정 조회를 서버에서 수행한다. OAuth 콜백만 공개 허용하고 연결 관리·검토·게시 기능은 로컬에 둔다. 토큰은 서버에 암호화하여 보관하고 클라이언트에는 계정과 연결 상태만 제공한다. 공개 콜백과 로컬 API는 같은 인증 저장 경로를 공유한다.

## Publication Image Upload
검토 화면에서 게시용 JPG·PNG·WebP를 선택하고 정확한 변환 결과를 미리 본 뒤 저장한다. 게시용 JPEG는 별도 서버 폴더에 보관하며 Publish 때만 1시간 유효한 서명 URL을 Meta에 제공한다. 수신 원본 이미지는 자동 공개하지 않는다.

## Photo Prompt Creation
로컬 기본 화면에서 사진만으로 4:5 뉴스 표지와 게시문을 생성한다. 추가 기사 맥락은 선택 사항이다. 사진 분석 모델은 제목·캡션을 반환하고 Python Pillow가 원본 전체를 비율 유지해 배치한 뒤 별도 하단 영역에 제목을 합성한다. 사람과 얼굴은 그대로 보존한다. 가림 처리가 필요 없는 사진을 사용하며 자동 마스킹은 적용하지 않는다. 이 경로에서는 생성형 이미지 변형을 사용하지 않는다. 사람은 결과를 검토하고 Publish로 게시한다. 기존 홈서버 수신·검토와 계정 연결은 유지한다.

## Sensor Editorial Defaults
관측 수신 기사는 짧은 후크·줄바꿈·따뜻한 관찰자 말투·선택형 질문을 기본으로 한다. 피에조 충격은 센서 신호로만 다루며 원인·가해자·범죄·감정을 창작하지 않는다. 센서 장비 연결·임계값·수신 규약은 이번 변경에 포함하지 않는다.


## Current Card News POC
사용자 요청(2026-11-06): 공개 기본 화면과 `/poc`는 사진+큰 흰색 헤드라인+하단 어두운 그라데이션의 커버 1장, 내용 카드 3장으로 구성한 4장 카드뉴스 체험이다. 사진 배경에 자동 가림 처리를 하지 않고 원본 장면을 보존한다. 단계 0은 어그로성 기자, 1은 조금 착하게, 2는 완전 아첨이며 제목·본문·게시문 모두에 적용한다. 수동 피에조 단계 제어로 실물 센서를 시뮬레이션한다. 공개 결과는 다운로드할 수 있고, 실제 Instagram 캐러셀 게시와 저장된 초안 검토는 로컬 화면에서 수행한다. Claude API ON이면 사진·맥락을 Anthropic으로 전송하고 OFF이면 Ollama를 사용한다. 기존 `/capture`의 단일 기사 체험은 유지한다.

## Server Automatic Publishing

2026-11-06 후속 변경: 기본 웹과 `/poc`는 서버 자동 게시 모니터다. 기존 사진·텍스트 수신 API를 유지하고, 서버가 각각 새 입력 하나를 묶어 카드뉴스 4장 생성과 Instagram 게시를 실행한다. 생성 시작부터 게시 완료까지 사진·텍스트를 409로 거절하고 저장·대기열·후속 게시하지 않는다. 게시 완료 시 다음 쌍을 받는다. 생성·게시 실패나 결과 불명확, 처리 중 재시작은 확인 대기로 중지하고 모니터의 관리자 영역에서 확인 후 새 입력 수신을 재개한다. 별도 수동 게시 화면은 제거한다. 원래 사진 eventId로 모바일 상태·SSE를 유지한다. 과거 저장 입력은 자동 재사용하지 않는다.

## Claude Only

2026-11-06 후속 요청: AI 사진 분석·기사·카드뉴스 본문·이미지 비교는 항상 Claude API를 사용한다. 기존 AI OFF 설정과 TEXT_PROVIDER는 무시하며 로컬 추론 대체 경로를 두지 않는다. 키 누락·네트워크·API 오류는 명시적 실패로 처리한다. 화면은 Claude 설정 상태만 표시하고 관리자 인증은 유지한다. 카드 이미지의 Python/Pillow 합성과 기존 별도 캡처의 음성 전사 기능은 유지한다.

2026-11-06 텍스트 선택 입력: 사진 수신 후 최대 40초 동안 텍스트를 기다린다. 먼저 도착하면 즉시 생성하고, 없으면 사진만으로 생성·게시한다. 타임아웃 이후 사진 없는 텍스트는 거절한다. 촬영 식별자가 없는 텍스트는 다음 사진 이후 도착 시 이전 촬영 건 여부를 구분할 수 없다.

카드뉴스 작성 전 원본 사진의 초점·흔들림을 검사한다. 심하게 흐리거나 번져 핵심 피사체·장면을 식별하기 어려운 사진은 기사·카드뉴스를 생성하거나 게시하지 않고 스킵한 뒤 다음 사진 수신을 기다린다. 배경 흐림이나 약한 흔들림이 있어도 주요 장면을 식별할 수 있으면 진행한다. 품질 판단 실패는 스킵으로 간주하지 않고 생성 실패로 처리한다.
